# ScamShield

ScamShield is a modern AI-powered cybersecurity platform focused on detecting phishing attempts, scam messages, malicious links, and fraudulent communication in real time.

The platform is designed to provide users with a simple and accessible way to analyze suspicious content before interacting with it.

## Features

### AI Scam Detection

Analyze:

* SMS messages
* Emails
* WhatsApp messages
* URLs and links

The system classifies content as:

* Safe
* Suspicious
* Scam

along with a risk score and detailed explanation.

---

### Explainable Threat Analysis

ScamShield identifies and explains:

* urgency-based manipulation
* phishing indicators
* suspicious domains
* fake reward tactics
* social engineering patterns

---

### Blockchain Verification Layer

Includes a blockchain-inspired trust layer to:

* identify previously reported scams
* maintain immutable report history
* improve trust verification

---

### Community Reporting

Users can report suspicious messages and links to strengthen collective threat intelligence.

---

### Analytics Dashboard

Interactive dashboards provide insights into:

* detection activity
* scam trends
* common attack categories
* threat statistics
